# AI usage disclosure

This project used AI assistants during development. Sol handled the primary implementation and integration, including architecture and financial logic. The finance agent handled bounded finance services and related checks. Luna handled bounded interface work and official-source research/data curation.

No optional LLM API is used by the application. The scenario lab uses a deterministic local calculation. AI-generated or AI-assisted implementation remains the team's responsibility and should be reviewed by the named human submitters before any competition submission. The competition page permits AI tools when disclosed and places responsibility on entrants.

Before submission, the team should add the actual names and affiliations of contributors and confirm this disclosure accurately covers all work and tools used. Do not claim that AI was unused.
