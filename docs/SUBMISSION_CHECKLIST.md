# Submission checklist

Competition reference: [NISR 2026 Big Data Hackathon](https://www.statistics.gov.rw/about/hackathon/2026-hackathon-competition). The published submission deadline is 30 October 2026, 11:59 PM; the page does not state a timezone. Registration closed 20 October 2026.

Items remain unchecked until the team supplies and verifies them. A local file or running local demo does not count as a public submission link.

- [ ] Confirm student eligibility and two-person team, including at least one Rwandan citizen; retain required student or official eligibility proof.
- [ ] Confirm no team member is disqualified as a prior first-, second-, or third-place winner.
- [ ] Review final code, data provenance, AI disclosure, originality statement, and competition IP assignment with all entrants.
- [ ] Publish the repository publicly on GitHub and verify the submitted link works.
- [ ] Deploy the app to an accessible public URL and verify the submitted link works.
- [ ] Prepare and review submission documentation, including project purpose, operation, official data sources, methodology, synthetic-data disclosure, limitations, and AI usage.
- [ ] Record and review the three-minute screen walkthrough in [DEMO_GUIDE.md](DEMO_GUIDE.md); attach its final link or file as requested by the competition.
- [ ] Check the competition page for amendments and confirm the deadline timezone with NISR.
- [ ] Submit the required public GitHub link, deployed app link, and documentation before the deadline; retain the confirmation.
